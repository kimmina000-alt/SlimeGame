## 최신 확정 규칙 요약

- 개인 구역 1개당 슬라임 1개.
- 슬라임 베이스 1종, 장착 토핑 최대 3개.
- 개인 구역당 노동자 1명 고정.
- 기존 6개 패드와 패드별 해금 구조 제거.
- 던전 3단계: 초급 동굴 / 중급 동굴 / 심층 동굴.
- 모든 던전과 개인 구역은 PvP 불가 평화 구역.
- 더티 토핑은 던전에서 발굴하고 개인 구역에서 세척한다.
