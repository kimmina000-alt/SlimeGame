## 최신 핵심 규칙
- 서버 최대 15명, 개인 구역 15개를 원형 배치.
- 개인 구역마다 슬라임 1개, 베이스 1종, 토핑 최대 3개.
- 개인 구역마다 노동자 1명, 오프라인 수익 없음.
- 패드 6개/패드별 해금/구역 확장 구조 제거.
- 초급·중급·심층 던전 3개, PvP 전면 비활성화.
- 더티 토핑은 던전 흙더미를 발굴해 획득하고 개인 구역에서 세척.
- 가방은 더티 토핑 무게에만 적용.
- 던전마다 베이스 펌프 1개, 플레이어별 5L/20초 쿨타임/10L 한도.
